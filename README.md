# Tesi Benchmark

Questo progetto nasce per la mia tesi di laurea e simula il flusso di lavoro di una linea industriale per il taglio delle bobine.

Comprende un pannello operatore, un sistema MES e un simulatore PLC che scambiano dati tramite file JSON.

Per aprirlo in Visual Studio usare `CoilCutIntegratedSystemLegacy.sln`.
